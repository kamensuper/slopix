# Let There Be Light design implementation

The current implementation uses original blue/teal Azure tide wallpaper, glossy
opaque gradients, compact tabs, soft edge shadows and antialiased original PNG
icons. Five appearance choices reuse compatible persisted preferences. Panel
Classic/Dock/Minimal presets remain independent of native screen resolution.

Actual final-ISO captures are build/light-desktop-800-600.png,
build/light-desktop-1280-800.png and build/light-desktop-1920-1080.png. These are
running guest pixels, not concepts. SDL host-window refresh is separately tested.

SlopDE-2-Design.pdf and slopde2-concept.png are preserved Pre-Genesis design
references, not promises that every concept feature is present. LIGHT-BRIEF.txt
is the newer comprehensive request. RELEASE-LIGHT.md and
KNOWN-LIMITATIONS-0.9.md classify the implemented and deferred portions.
